This mod removes the container labels from most of the interactable blocks and entities, excluding the modded ones. It also removes the `Trades` text from the villager GUIs.

But you may ask why would anyone even need this? This mod exists because I was so annoyed by how other languages except EN_US displayed duplicate texts on the containers when using resourcepacks like [GUI Revision](https://modrinth.com/resourcepack/gui-revision) which adds the container names to the pixel art of the container.
